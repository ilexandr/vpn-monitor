# Серверные изменения

## 26.10.2026 — управление пользователями в Web

Добавлены admin-only CRUD API, форма в обеих темах, CSRF, безопасная валидация, блокировка/смена пароля/удаление. Admin из env защищён; привязка обычного пользователя к одноимённой группе сохранена.

База перенесена в каталог данных службы с сохранением аккаунтов. Веб/CLI сериализуют записи общим flock; записи атомарны. Старый путь сохранён ссылкой. Backup включает базу/CLI и использует общий lock.

Изменения установлены на рабочем сервере. Реальные проверки создания/пароля/блокировки/удаления, отказа обычному пользователю, совместной записи root/службы, API мониторинга и backup пройдены. Временные аккаунты удалены; существующие записи сохранились. См. docs/WEB_USER_MANAGEMENT_VERIFICATION.md.

Windows-клиент остаётся 0.1.75. Управление пользователями в программе — отдельный следующий этап; API подготовлен.
