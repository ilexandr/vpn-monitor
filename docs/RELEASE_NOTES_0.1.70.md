# VPN Monitor 0.1.70

Один пакет изменений главного окна, настроек и действий с клиентами.

## Главное окно

- В шапке оставлены обновление, AWG, «Ещё» и настройки. Журнал, диагностика, CSV, Web и проверка обновлений доступны из «Ещё».
- Убраны дублирующая ссылка конфигурации и длинная постоянная памятка. Подробное состояние AWG доступно во всплывающей подсказке строки состояния и в окне AWG; ошибки соединения остаются видимыми.
- В меню колонок добавлены «Основные колонки» и «Все колонки». Существующий выбор колонок не сбрасывается; основные — AWG, компьютер и VPN IP, доступность остаётся отдельной колонкой.
- Строки списка компактнее. Ctrl+F переводит фокус в поиск, F5 обновляет данные.

## Настройки

- Все семь разделов находятся в одной непрерывной ленте. Нажатие слева прокручивает к разделу; при ручной прокрутке выделение следует за текущим разделом.
- Поиск прокручивает к найденному параметру, включая параметры выпадающих списков. Несохранённые значения остаются в форме.
- Проверка подключения находится в разделе подключения. Импорт/экспорт и общие кнопки сохранения/отмены остаются закреплены снизу.
- Общие стили полей ввода и пароля, кнопок, фокуса, подсказок, списков и таблиц работают в обеих темах. Главная кнопка сохранения выделена.

## Действия

- «Настройки → Действия → Настроить действия»: встроенные команды заполнены по умолчанию, собственные команды остаются доступны.
- Встроенные: избранное, уведомления, RDP, SSH, оба режима Radmin, общие папки, Ping, Tracert, история и копирование имени/адресов.
- Можно изменить название и группу, скрыть команду, изменить порядок внутри встроенных или собственных команд. Встроенные можно вернуть по умолчанию, сохранив свои команды.
- Команды обоих типов с одинаковой группой объединяются в одном подменю ПКМ. По умолчанию подключения, диагностика и копирование сгруппированы; общие папки сохраняют вложенное меню.
- Встроенные команды сохраняют свои обработчики, проверки IP, окна и запросы учётных данных. Они не превращаются в произвольные строки запуска.
- Настройки меню переносятся через импорт/экспорт; отмена редактора и отмена настроек не применяют изменения. Старые настройки получают встроенные значения по умолчанию, собственные команды остаются включёнными.
- Настройки видимости относятся к меню ПКМ; быстрые кнопки карточки клиента остаются доступны.

## Проверить после обновления

1. Меню «Ещё», обновление F5, поиск Ctrl+F и выбор наборов колонок.
2. Прокрутку настроек вниз/вверх, переходы по меню, поиск параметра, сохранение и отмену.
3. Встроенные и свои действия: общую группу, скрытие, изменение названия/порядка; возврат встроенных по умолчанию.
4. Светлую/тёмную темы и привычный масштаб Windows.

Проверки выполнены на настоящих WPF-контролах, включая минимальную ширину, поиск в закрытом выпадающем списке, содержимое полей, прокрутку и изоляцию редактора. Одновременные RDP-сеансы пользователь ранее проверил и подтвердил работу; изменения этого пакета требуют обычной визуальной проверки после обновления.
