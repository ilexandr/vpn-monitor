# VPN Monitor 0.1.63

Первый релиз для обновления через GitHub Releases.

- Обновление из приложения: «О программе» → «Проверить обновления» → «Обновить».
- Установщик Windows x64 включает .NET, клиент, менеджер и движок AWG.
- Автономное обновление закрывает установленные клиент и менеджер во всех сеансах, временно останавливает общий туннель VPN Monitor и восстанавливает то, что работало.
- Настройки пользователей и защищённые профили сохраняются.
- При обновлении сохраняется тип запуска службы; после установки проверяется версия.
- Контрольная сумма SHA-256 установщика доступна в файле SHA256SUMS и метаданных GitHub.

Для обновления из 0.1.62 нужен доступ к GitHub и подтверждение UAC. Если программа старее 0.1.62, используйте установщик вручную.

Проверено: сборка, регрессионные проверки, защищённый IPC, сценарии восстановления и валидация AWG без подключения. Цикл обновления на сервере и нескольких RDP-сеансах требует проверки на установленной версии.
