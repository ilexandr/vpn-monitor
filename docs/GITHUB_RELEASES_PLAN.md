# GitHub и релизы

Репозиторий: ilexandr/vpn-monitor — публичные исходники и релизы, выбор пользователя.
GitHub подключён к ilexandr. Создание пустого репозитория ожидается в интерфейсе GitHub: подключение не предоставляет операции создания репозитория.
Удалённый репозиторий ещё не создан; исходники и релизы не опубликованы.

## Доступ
Предпочтителен GitHub-плагин с авторизацией пользователя. Пароли и приватные ключи не переносить в чат или репозиторий. Реальные возможности создания/публикации проверить после подключения; при необходимости настроить GitHub CLI через вход в браузере.

## Подготовка публикации
- Проверить список файлов и выполнить проверку на секреты до первого push.
- TEST.conf и другие VPN-профили, DPAPI-файлы, локальные настройки/CSV, логи и отчёты исключены .gitignore.
- Инструменты сборки и клон upstream AWG не включать как вложенный Git-репозиторий: закрепить commit, лицензии и локальные изменения отдельным воспроизводимым шагом.
- Убрать зависимость проверок от рабочего профиля и сети из CI.
- Тестовые учётные данные должны оставаться синтетическими.
- Подготовить корневой README, описание компонентов и сборки.
- Не выбирать лицензию проекта от имени пользователя без решения о лицензировании; сохранить уведомления сторонних компонентов.

## Релизы и инсталлятор
Версионированные GitHub Releases с Windows-установщиком, контрольными суммами, описанием изменений и информацией о совместимости компонентов службы.
Для приватного репозитория понадобится отдельная схема получения обновлений; общий токен владельца в клиент не встраивать.
При приватных исходниках возможен отдельный публичный репозиторий артефактов.
Установщик обновляет компоненты под UAC, сохраняет личные настройки и защищённые профили, учитывает все активные сеансы и даёт возможность отката.
