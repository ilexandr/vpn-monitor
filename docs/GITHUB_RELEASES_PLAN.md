# GitHub и обновления

Репозиторий: ilexandr/vpn-monitor. Исходники и релизы открыты.

## Сборки и публикация
- Windows x64: установщик и контрольные суммы SHA-256.
- Релизы публикуются в GitHub Releases после проверки сборки и установки.
- Профили VPN, ключи, пароли, DPAPI-файлы, журналы и пользовательские настройки не включаются в репозиторий или дистрибутив.
- Версия движка AWG закреплена; лицензии зависимостей включаются в установщик.
- Обновление не должно останавливать общий туннель или приложения других пользователей без явного действия администратора.

## План обновлений
Проверка новых версий через GitHub Releases, показ изменений и скачивание установщика с проверкой контрольной суммы. Установка общих компонентов требует UAC. Настройки пользователей и защищённые профили сохраняются.

Реализовано с v0.1.62–0.1.65: «О программе» → проверка версии → обновление с UAC. Координатор закрывает экземпляры приложения и менеджера во всех сеансах, останавливает собственный общий туннель и восстанавливает ранее работавшие компоненты после установки. Контроль целостности — SHA-256 из GitHub API; при ошибке предусмотрена резервная копия двоичных файлов.

Установка, обновление и автоматическое удаление проверены локально; пользователь подтвердил успешное обновление на сервере до 0.1.65. Одновременные реальные RDP-сеансы требуют отдельной проверки. Частичные обновления отложены; небольшие изменения объединяются в один релиз.
