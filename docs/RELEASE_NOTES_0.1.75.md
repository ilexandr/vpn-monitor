# AWG Dash Monitor 0.1.75

- В менеджере добавлена «История связи…»: последние 200 событий общей службы сохраняются между запусками. Показаны Endpoint, подтверждение потери, попытки переподключения, подтверждённая работа резерва и результаты ручных проверок. История общая для профилей и Windows/RDP-сеансов; ключи в неё не записываются.
- «Проверить резерв…» при исправном основном соединении: служба временно использует резервный Endpoint, проверяет входящий трафик собственного AWG и возвращается к основному после успеха или таймаута. Возврат также проверяется; при его отказе включается обычное восстановление. Закрытие менеджера не прерывает тест; ручная остановка службы остаётся остановкой. Конфигурация профиля не меняется.
- Проверка запускается только после подтверждения, при заданном резерве, исправном основном и свободном бюджете попыток. Повторная проверка недоступна минимум 10 минут. Команды привязаны к текущему процессу службы и имеют срок действия; одна служба выполняет проверку за все сеансы.
- В «О программе» после проверки GitHub доступен «Состав версии…»: доверенный манифест проверяется по SHA-256, версии и исходному commit, затем сравнивается с установленными файлами. Показаны совпадающие/изменённые файлы и объём без сжатия. Доступно и для текущего релиза. Это следующий этап частичных обновлений; установка пока использует полный пакет.
- При переподключении старый трафик не подтверждает новый Endpoint. Ошибка применения Endpoint или подъёма интерфейса не считается успешным восстановлением.

Проверить после обновления:
1. Открыть «История связи…», посмотреть события после подключения и при переходе на резерв.
2. Вернуть корректный основной Endpoint и подключиться через него. Когда кнопка «Проверить резерв…» станет доступна, запустить проверку: дождаться подтверждения резерва и возврата основного. Можно закрыть менеджер и открыть снова — результат останется в истории. При работе через резерв кнопка недоступна.
3. В «О программе» проверить GitHub и открыть «Состав версии…». Оценка не меняет файлы и соединение.
