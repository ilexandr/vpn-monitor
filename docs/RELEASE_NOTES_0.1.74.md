# AWG Dash Monitor 0.1.74

- Полный редактор конфигурации туннеля в менеджере AWG. Существующие ключи скрыты; маски сохраняют их без изменений, новое значение позволяет заменить ключ. Сохранение при остановленной службе, с проверкой движком, политикой восстановления и защитой от изменений из другого RDP-сеанса. Профиль атомарно сохраняется с DPAPI и применяется при следующем подключении.
- Основной и резервный Endpoint видны для выбранного профиля. Показаны ответ ICMP резервного узла, время проверки и подтверждённое состояние резервного AWG при его использовании. Ping не считается доказательством исправности AWG. Автоматическое переключение для такой проверки не выполняется.
- Новое имя: AWG Dash Monitor (ранее VPN Monitor). Обновлены окна, трей, установщик и ярлыки «Пуск». Существующие настройки, служба, профили и канал обновлений совместимы.
- Менеджер сохраняет строки списка при обычном опросе; содержимое доступно с прокруткой при маленьком окне. Устаревшее состояние от предыдущего процесса службы не используется.
- Первый этап частичных обновлений: файловый манифест релиза с размерами/SHA-256 и локальный расчёт отличий. Автоматическое обновление пока загружает полный установщик; файловые пакеты с откатом — следующий этап.

Проверить после обновления: новое имя и ярлыки; «Конфигурация…» (изменение Endpoint/параметра, сохранение и последующее подключение); блокировку сохранения при работающем туннеле; адрес и ICMP-состояние резерва. Реальное переключение на резерв проверить отдельно в подходящее время: оно затрагивает всех пользователей.
