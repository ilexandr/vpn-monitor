# VPN Monitor 0.1.66

Небольшие улучшения объединены в один релиз.

- В истории клиента появился поиск по всем словам: время, источник, предыдущее и новое значения. Новые подходящие события появляются сразу, без повторного открытия окна.
- Экспорт CSV сохраняет текущий результат поиска и порядок строк. UTF-8 с BOM, даты с часовым поясом, экранирование кавычек/переносов строк и защита от формул таблиц.
- В окне общего туннеля AWG отображаются время последней проверки состояния и время последней успешной связи. После неудачной проверки время успешной связи сохраняется; при смене сервера сбрасывается.
- README и план приведены в соответствие с готовыми установкой, обновлениями, управлением AWG и серверной авторизацией.

История остаётся сеансовой: до 2000 событий на всех клиентов. Проверки связи продолжают работать с прежним интервалом; дополнительная сетевая нагрузка не добавлена. Переработка настроек и частичные обновления отложены.

Проверить после обновления:
1. ПКМ по клиенту → «История клиента»: поиск `AWG Offline`, затем очистка поиска; события других клиентов не должны появляться.
2. «Экспорт CSV…»: в Excel или другом редакторе проверить русский текст, время и соответствие текущему фильтру/сортировке истории.
3. Окно общего туннеля: при доступной связи время успешной проверки обновляется; при потере связи сохраняется последнее успешное время.

Автоматические проверки: полный RegressionChecks; дополнительные проверки фильтра в настоящем WPF-окне, живого поступления событий, CSV и сброса времён проверки.
