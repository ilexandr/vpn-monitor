# Проверка 0.1.78 — 29.10.2026

- Старые HttpClient/помощник обновления наследовали default/system proxy. В .NET 8 WebRequest.GetSystemWebProxy возвращает HttpClient.DefaultProxy: https://github.com/dotnet/runtime/blob/v8.0.0/src/libraries/System.Net.Requests/src/System/Net/WebRequest.cs . В этой версии транспортная политика задана явно и не использует системный default proxy.
- Сборка RegressionChecks без ошибок и предупреждений; полный набор — 43 PASS.
- В процессе теста default proxy заменён на несуществующий localhost:1: прямой HttpClient выполнил настоящий запрос к локальному серверу. Затем настоящий тестовый HTTP-прокси получил запрос с absolute URI для несуществующего origin; серверный API проверен с отдельным opt-in, переключение обратно на direct работает без перезапуска.
- Отклонены SOCKS/HTTPS адреса самого прокси, userinfo/пароль, путь/query/fragment, нулевой порт и управляющие символы. CONNECT для HTTPS выполняет штатный HTTP-стек; собственный TLS-прокси не реализован.
- Импорт/экспорт сохраняют политику. Несохранённый черновик формы не меняет текущую политику. Обе темы формы проверены визуально. Проверка трея подтверждает «О программе…» вместо «Обновить» и общий стиль меню.
- Installer/Test-Proxy.ps1 запущен настоящим Windows PowerShell 5: исполнен транспортный блок самого updater, default proxy очищается, manual proxy применяется к WebRequest/WebClient, некорректные адреса отклоняются. Этот тест проверяет конфигурацию транспорта без установки и без остановки туннеля.
- Test-ServiceRecovery, Test-UpdateResume, Test-UpdateFilePlan — PASS.
- Системный прокси, VPN-туннель и настройки реального пользователя во время тестов не менялись. Полная живая установка/обновление через домашний прокси пользователя остаётся пользовательской проверкой.
