# VPN Monitor 0.1.72

- Исправлен белый фон списка профилей AWG при подключении и отключении в тёмной теме. Заблокированный список сохраняет цвета приложения.
- Общие диалоги подтверждения, информационные сообщения и ошибки внутри клиента и менеджера AWG оформлены в теме приложения. Подключение и отключение имеют явные кнопки действия; отмена остаётся выбором по умолчанию. Системные файловые диалоги и аварийное сообщение при невозможности запуска остаются системными.
- На недоступном клиенте TCP-проверки сервисов приостанавливаются: вместо отдельного сбоя сервиса показывается «Клиент Offline». Активная проверка доступности имеет приоритет над статусом AWG. После возвращения клиента подтверждение сбоя начинается заново; прежние инциденты сервисов прерываются, отложенные уведомления отменяются.
- При опросе API сохраняются объекты строк клиентов. Список перестраивается только при изменении видимого состава или порядка; значения, фильтры и сортировка продолжают обновляться. Подсказки доступности и сервисов обновляют содержимое без замены самого окна подсказки.
- Устранено краткое открытие сетевых интерфейсов перед главным окном при двойном клике по трею. Одиночный клик обрабатывается после системного интервала двойного клика.
- Меню трея использует цвета текущей темы, Segoe UI и единые отступы. Добавлены сетевые интерфейсы и настройки, сохранены открытие, обновление и выход.
- В план добавлены настройки профилей AWG с основным/резервным Endpoint, политикой переключения и возврата для общего туннеля. Также добавлено будущее переименование с сохранением совместимости установок и обновлений; название пока не выбрано.

## Что проверить

1. В тёмной теме менеджера подключить и отключить туннель: список не белеет; отмена подтверждения не меняет состояние.
2. На офлайн-клиенте в колонке сервисов видно «Клиент Offline»; после появления клиента проверки возобновляются. Отдельный закрытый порт онлайн-клиента по-прежнему даёт сбой после трёх проверок.
3. Навести мышь на доступность или сервисы и дождаться нескольких обновлений: подсказка не исчезает из-за обычного опроса.
4. Одинарный клик по трею открывает интерфейсы с небольшой системной задержкой; двойной — только главное окно. Проверить меню в обеих темах, закрытие по Escape и работу на сервере в RDP.

Автоматическое переключение Endpoint и переименование ещё не реализованы.
