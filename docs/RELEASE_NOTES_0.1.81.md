# AWG Dash Monitor 0.1.81

- При запуске установщика вручную больше не требуется заранее закрывать приложение и останавливать общий туннель. Окна сохраняют состояние и запускаются заново в своих сеансах Windows.
- После установки восстанавливается только тот туннель, который работал до подготовки. Остановленный туннель остаётся остановленным. Восстановление проверяет настоящее соединение, а не только статус службы.
- Отмена или ошибка установки также запускает восстановление. Повторный вход на страницу подготовки сохраняет первоначальное состояние; посторонняя служба не останавливается.
- Одновременно допускается один экземпляр установщика. Шифрованные профили и пользовательские настройки сохраняются.

На время замены файлов общий туннель прерывается во всех Windows-сеансах. Проверка с имитацией служб выполнена без отключения рабочего подключения; живую установку поверх работающего туннеля необходимо проверить отдельно.
