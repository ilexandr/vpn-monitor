# AWG Dash Monitor 0.1.76

Управление пользователями серверного мониторинга теперь доступно из Windows-программы: «Ещё → Управление пользователями…» под admin при действующем соединении.

- Список аккаунтов, создание по имени группы, смена пароля, блокировка и удаление. Можно выбрать имя из существующих групп WGDashboard.
- Используется общая с веб-интерфейсом база. Создание аккаунта не создаёт группу или VPN-клиента; удаление аккаунта сохраняет их.
- Основной admin защищён; обычным пользователям управление недоступно. Перед каждой записью повторно проверяются права и CSRF. При смене учётной записи окно закрывается.
- Смена пароля передаёт только изменённые поля. При таймауте запись не повторяется автоматически: требуется обновить список и проверить результат. Пароли и серверные тела ошибок не записываются в журнал.
- Окно оформлено в общей светлой/тёмной теме, «Закрыть» справа.

Проверить после обновления:
1. Под admin открыть «Ещё → Управление пользователями…», создать тестовый аккаунт для нужной группы и проверить вход с ним.
2. Сменить пароль, заблокировать и снова разрешить вход; проверить те же изменения в веб-интерфейсе.
3. Удалить тестовый аккаунт. Группа и VPN-клиенты должны остаться. У обычного пользователя пункта управления быть не должно.
