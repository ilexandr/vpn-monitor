# VPN Monitor 0.1.65

- При потере связи общий и групповые счётчики показывают неизвестное состояние (—/всего) вместо старого количества Online/Offline. После успешного запроса данные восстанавливаются.
- Удаление программы само завершает клиент и менеджер во всех сеансах установленной программы и останавливает её общий AWG-туннель. Профили и личные настройки сохраняются.
- При восстановлении туннеля после обновления предусмотрены ожидание и три попытки запуска; ошибки с кодами службы записываются в журнал.
- Установщик умеет восстанавливать ранее работавший туннель для старого помощника обновления. Обычная ручная установка не включает отключённый туннель.
- Частичные обновления добавлены в план: загрузка изменившихся файлов по манифесту SHA-256, проверка и откат. Пока используется полный установщик.

Серверная ошибка восстановления, замеченная при обновлении обычным пользователем, пока не воспроизведена локально. Новая обработка повышает надёжность и позволяет собрать точную причину. При повторении нужны host-startup.log, ошибки службы Windows и журналы service-recovery.jsonl / installer-service-recovery.jsonl из каталога обновления ProgramData/VpnMonitor/Updates.

- Исправлена запись каталога установки в реестр: существующий ключ не удаляется и записывается в 64-битное представление.
- Ошибка настройки компонентов после копирования файлов теперь возвращает ненулевой код завершения установщика.
