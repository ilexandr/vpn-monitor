# Проверка 0.1.74 — 25.10.2026

- Сборка RegressionChecks и менеджера: без предупреждений и ошибок.

- Test-UpdateFilePlan: неизменные/отсутствующие/повреждённые файлы, traversal, NTFS streams, зарезервированные имена и дубли — PASS.
- Test-ServiceRecovery и Test-UpdateResume: PASS; сохранены восстановление пользователей, обработка сбоя помощника и защита от дубликатов.
