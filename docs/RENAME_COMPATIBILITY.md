# AWG Dash Monitor: совместимость переименования

Название согласовано пользователем 25.10.2026. В 0.1.74 изменены окна, трей, «О программе», свойства Windows-приложения, название установщика и ярлыки «Пуск».

Сохраняются: `ilexandr/vpn-monitor`, URL GitHub Releases и имена установочных файлов, AppId Inno Setup, `Software\VpnMonitor`, путь установки `VpnMonitor`, exe/assembly, имена службы и IPC, задача/ключ автозапуска, ProgramData/AppData, DPAPI-описания и формат профилей. Это обновление существующего продукта, второй экземпляр продукта или новая служба не создаются. Старые три штатных ярлыка «Пуск» заменяются новыми. Пользовательские ярлыки сохраняют работоспособность благодаря прежнему пути exe.

GitHub пока не переименовывается: старым клиентам нужен закреплённый источник обновлений. Возможный будущий перенос требует промежуточной версии с поддержкой двух проверенных адресов и отдельной проверки помощника обновления. Менять идентификатор службы, AppId и хранилища ради отображаемого имени не требуется.

Отношение к WGDashboard описано в «О программе»; продукт не заявляется официальным клиентом проекта WGDashboard. Серверный протокол и название существующего развёрнутого Web-интерфейса этой установкой Windows не меняются.
