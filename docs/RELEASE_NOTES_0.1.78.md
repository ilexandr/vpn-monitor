# AWG Dash Monitor 0.1.78

Исправлена зависимость HTTP-запросов от системного прокси Windows: после отключения VPN/локального прокси обновления больше не должны обращаться к оставшемуся адресу вроде 127.0.0.1:10809.

- В «Настройки → Подключение» добавлены режимы «Без прокси» (по умолчанию) и «HTTP-прокси». Для своего прокси указывается адрес http://host:port без авторизации. HTTPS-запросы проходят через HTTP-прокси стандартным CONNECT.
- Проверка обновлений, состав версии и помощник загрузки установщика используют один выбранный режим. Помощник получает его от исходного пользователя и не наследует прокси другой учётной записи после UAC. Выбор действует после сохранения, без перезапуска программы.
- Для API мониторинга и управления пользователями прокси включается отдельной галочкой; по умолчанию эти запросы идут напрямую. Настройки прокси не меняют работу AWG-туннеля и системные параметры Windows.
- Настройки участвуют в импорте/экспорте; адрес проверяется, логин/пароль в URL запрещены. При выборе собственного прокси программа не переключается незаметно на прямое соединение при его отказе.
- В контекстном меню трея «Обновить» заменено на «О программе…», откуда доступны проверка версии, обновление и диагностика.

Проверить:
1. При выключенном системном VPN/прокси открыть «О программе…» из трея и проверить обновления в режиме «Без прокси».
2. Если нужен свой HTTP-прокси, сохранить адрес в настройках и повторить проверку. После переключения обратно на прямой режим перезапуск не требуется.
3. Убедиться, что мониторинг клиентов продолжает работать, а в меню трея появился новый пункт.

Если старая версия не может скачать обновление из-за прежнего прокси, этот первый установщик можно скачать вручную со страницы релиза.
