# AWG Dash Monitor 0.1.82

- Установщик не предлагает запускать приложение повторно, если оно уже восстанавливается после установки в этом Windows-сеансе. Восстановление клиента другого RDP-сеанса не скрывает предложение запуска для текущего пользователя.
- Повторный вход на страницу подготовки сохраняет этот выбор.
- Дополнительная защита не позволяет запустить второй клиент для того же пользователя в том же Windows-сеансе. После завершения или аварийного выхода блокировка освобождается автоматически; другие RDP-сеансы работают независимо.

Проверка: установить поверх работающего клиента — приложение должно восстановиться один раз, без галочки повторного запуска. При установке с закрытым клиентом предложение запуска должно остаться.
