# AWG Dash Monitor 0.1.77

Исправлен запуск общего AWG-туннеля после перезагрузки Windows. До этой версии установщик создавал службу с запуском «Вручную».

- При обновлении установленный туннель с выбранным профилем один раз переводится на автоматический запуск с задержкой Windows. Вход пользователя и запуск основной программы не требуются. Службы, явно отключённые в Windows, автоматически не включаются.
- В менеджере AWG показан реальный режим службы и добавлена кнопка включения/отключения автозапуска. Настройка общая для всех Windows/RDP-сеансов и требует администратора. Смена режима не прерывает текущий туннель.
- Следующие обновления сохраняют выбранный режим. При переустановке учитывается сохранённая настройка. Чистая установка без профиля не запускает службу автоматически; после добавления профиля автозапуск можно включить в менеджере.
- При аварийном завершении или ошибке службы Windows выполняет две попытки перезапуска с задержками 30 и 60 секунд. Дальнейшие повторы прекращаются; счётчик сбрасывается после суток без сбоев. Обычная ручная остановка не вызывает восстановления. Внутренний мониторинг связи и переключение резервного Endpoint продолжают работать.
- При удалении выбранного профиля автозапуск отключается, чтобы не запускать службу без конфигурации.

Проверить после обновления на обоих компьютерах:
1. В менеджере AWG отображается «Автозапуск: включён, с задержкой Windows».
2. Перезагрузить компьютер и дождаться запуска службы с задержкой Windows. Туннель должен подняться без ручного подключения; проверить доступ к серверу.
3. При необходимости выключить автозапуск в менеджере: текущее соединение сохранится, после перезагрузки подключение выполняется вручную. Для постоянной работы вернуть автозапуск.
