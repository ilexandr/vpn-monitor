# Проверка 0.1.72 — 25 октября 2026

Исходный commit установщика: `4f3be8c1c960b459397811bcf74b78aebb3e7ccc`.

- Сборка клиента и RegressionChecks без предупреждений и ошибок. Полный RegressionChecks завершился с кодом 0 (37 групп проверок).
- Настоящее главное окно с управляемым API: повторный опрос сохраняет объекты клиентов и не посылает Reset представлению при неизменном составе/порядке. Проверены уведомления привязок статуса, трафика и групп. Шаблоны ячеек используют постоянный ToolTip и время показа не менее минуты.
- Проверки сервисов: офлайн-клиент не порождает TCP-запросов и получает нейтральное состояние без сбоя сервиса; после возвращения счётчик неудач начинается заново. Активная доступность имеет приоритет над устаревшим AWG Offline. Прежние тесты порогов, восстановления, интервалов, бюджета и параллельности прошли.
- Менеджер AWG с подставной асинхронной командой: заблокированный список сохраняет тёмный фон, тема не меняется; отложенное закрытие завершается после команды. Никакая команда не отправлялась рабочему туннелю.
- Настоящие WPF-окна менеджера и мониторинга отрисованы в обеих темах, включая минимальный размер; отдельно просмотрены изображение занятого менеджера в тёмной теме и новый диалог подтверждения. Проверены исходная отмена подтверждения и соответствие палитры меню трея теме.
- Существующие проверки доступа, изоляции аккаунтов/архивов, истории, настроек, диагностики, обновлений и инструментов сети прошли. Тестовые настройки и логи изолированы.
- Итоговый self-contained Windows x64 установщик собран; source commit из Licenses/build-info.json совпадает с указанным выше.
- Installer/Test-Layout.ps1 прошёл: объединённый runtime, путь с пробелами, отказ чужой службе и зарезервированным каталогам. Движок AWG принял тестовый профиль без запуска туннеля.
