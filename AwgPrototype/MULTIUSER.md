# Многопользовательский режим — 23.10.2026

- Туннель общий для машины. Его отключение влияет на все сеансы.
- Интерфейс, пароль API и личные настройки остаются в профиле каждого пользователя.
- Прототип использует SCM: управление только SYSTEM/Administrators, аутентифицированным пользователям — только запрос состояния.
- Запуск службы ручной, без автозапуска и без зависимости от входа/выхода пользователя.
- Файлы службы: Program Files/VpnMonitor/AwgPrototype; данные: ProgramData/VpnMonitor/AwgPrototype. ACL только SYSTEM/Administrators.
- Профиль защищается DPAPI LocalMachine и ACL; LocalMachine сам по себе не заменяет ACL.
- Журнал движка перенаправлен в собственную папку данных через conf.PresetRootDirectory, вместо Data установленного AmneziaWG.
- DLL загружается по абсолютному пути; поиск зависимостей ограничен системными и явно добавленной папкой приложения.
- Движок использует собственное имя и детерминированный GUID.
- Проверка пересечения AllowedIPs с активными маршрутами выполняется до старта, исключая системные default-маршруты и собственный адаптер. Ошибка чтения маршрутов блокирует запуск.
- На текущем ПК конфликт 10.20.0.0/24 обнаружен; сеть не изменялась.
- Установщик отказывается перезаписывать существующую службу/папки и проверяет защиту родительских каталогов.

Пока не реализованы: делегированная группа операторов, управление из GUI, установка/обновление/удаление через GUI, испытание подключения в отдельной VM и проверка двух реальных RDP-сеансов.
Не запускать тестовый туннель параллельно рабочему с пересекающимися маршрутами.
