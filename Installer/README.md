# Windows installer — 0.1.61 preview

Сборка Windows x64 для Windows 10 1809+ и совместимых Windows Server.
Включены self-contained .NET 8 приложения: клиент, host службы и административный менеджер; tunnel.dll, Wintun и уведомления о лицензиях.

## Сборка

Подготовьте .NET 8 SDK, Inno Setup 6, закреплённые Go/MinGW/Wintun.

    ./AwgPrototype/Prepare-Engine.ps1
    ./AwgPrototype/Prepare-Toolchain.ps1
    ./AwgPrototype/Build-Engine.ps1
    ./Installer/Build-Installer.ps1 -Compiler <path-to-ISCC.exe>

Результат: artifacts/releases/<version>/VpnMonitor-Setup-<version>-win-x64.exe и SHA256SUMS.
Сборочный скрипт не устанавливает приложение и не меняет рабочий туннель.
tools/ и artifacts/ не входят в Git.

## Установка и обновление

Установка на компьютер: каталог выбирается в мастере (по умолчанию Program Files/VpnMonitor); требуются права администратора. В конце есть флажок запуска клиента с обычными правами.
Перед установкой отключите общий AWG и закройте клиент/менеджер во всех сеансах. Установщик не закрывает их принудительно и не останавливает рабочий VPN.
Служба создаётся Manual/Stopped, без автоматического подключения.
При обновлении проверяется принадлежность службы приложению. Путь службы меняется на выбранный каталог; профили остаются в защищённом ProgramData.
После установки добавьте .conf через менеджер. Профили в установщик не включены.

## Пользователи и права

Двоичные компоненты доступны пользователям только на чтение/выполнение.
Machine DPAPI-профили доступны только SYSTEM/Administrators; публичный каталог содержит только названия/идентификаторы.
Настройки клиента остаются в профиле каждого пользователя Windows.
Удаление убирает регистрацию службы и установленные файлы; ProgramData-профили и личные настройки сохраняются.

## Проверено

- сборка трёх self-contained приложений и компиляция Inno;
- синтаксис PowerShell;
- отсутствие .conf/.dpapi/ключей/логов/личных экспортов в staging;
- регрессионные проверки клиента;
- фактический запуск setup на ПК с работающим AWG: отказ на PrepareToInstall, VPN остался Running, клиент не установлен.

## Ещё не проверено

Чистая установка, обновление/repair, удаление, восстановление после ошибки установки и параллельные RDP-сеансы. Не считать preview готовым для производственного сервера до этих проверок.
Установщик не подписан сертификатом издателя.
Автоматический CI/выпуск через GitHub Releases не добавлены: команда подготовки автоматизации отклонена проверкой безопасности без подробной причины. Репозиторий не содержит рабочего workflow выпуска.
Автоматическое обновление клиента не реализовано.

Версия 0.1.60: исправлена проверка скрытого ProgramData; при отказе выводится причина. Повторная сборка поддерживает защищённые от записи лицензии Go-модулей.

В 0.1.61 Client, Host и Manager используют один комплект DLL в Client. Старые известные файлы из AwgPrototype удаляются при обновлении в той же папке; неизвестные файлы сохраняются. При выборе другого каталога старые двоичные файлы остаются в прежнем каталоге.
