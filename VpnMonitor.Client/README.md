- Полностью убраны всплывающие сообщения о продолжении работы в трее при закрытии и сворачивании.

Проверка с настоящей сетью: выбрать клиента для уведомлений, дождаться доступности, отключить его и дождаться 3 неудачных циклов, затем включить. Отключение собственного туннеля должно давать неизвестный статус без массовых Offline. Для компьютеров с заблокированным ICMP включить резервный TCP-порт реально работающего сервиса. Контрольный адрес VPN Monitor должен быть доступен через проверяемый туннель; при адресе сервера вне VPN такая проверка не отличит обрыв локального VPN от недоступности всей группы.

## Контекстное меню клиента

Правый клик по строке клиента открывает тематическое меню:

- Копировать имя;
- Копировать VPN IP;
- Копировать External IP (берется host из endpoint, без порта);
- Пинг — запускает непрерывный `ping -t` в отдельном окне;
- RDP — запускает `mstsc /v:<VPN-IP>`;
- Общие папки — открывает `\\<VPN-IP>` в Проводнике;
- Radmin Viewer — Управление;
- Radmin Viewer — Передача файлов.

Строка клиента при ПКМ автоматически становится выбранной. После копирования/запуска действия краткое подтверждение показывается в нижней строке состояния.

## Radmin Viewer

В настройках появился блок **RADMIN VIEWER**:

- путь к `Radmin.exe`;
- кнопка выбора файла;
- порт Radmin Server (по умолчанию `4899`);
- логин по умолчанию (`Admin`);
- автоматическая подстановка логина в окно авторизации Radmin.

Если путь не задан, клиент пытается найти Radmin Viewer автоматически:

- рядом с VPN Monitor;
- в стандартных каталогах `Program Files` / `Program Files (x86)`;
- через Windows App Paths;
- через `PATH`.

Для управления используется прямой запуск Radmin Viewer к VPN IP. Обычный режим подключения Radmin Viewer — Full Control, а для передачи файлов используется ключ `/file`.

На удаленном ПК должен быть установлен и запущен Radmin Server, а у учетной записи Radmin должны быть разрешены соответствующие режимы подключения. Автоподстановка касается только логина: пароль Radmin VPN Monitor не хранит и не вводит.
